## Overview

**TaskFlow** is a full-stack "I Done This" style productivity platform that helps individuals and teams track daily accomplishments, visualize progress, and leverage AI-powered insights for continuous improvement.

Unlike traditional todo apps, TaskFlow focuses on **what you've already accomplished** - encouraging reflection, celebrating wins, and identifying growth opportunities through smart analytics.

## Key Features

### Daily Journal Log

- Add/update/delete tasks with status tracking (Done, Doing, Delayed)
- Date-based organization with automatic date stamping
- Optimistic UI updates for seamless experience
- Rich text descriptions and task notes

### Calendar View

- Interactive monthly calendar with task status indicators
- Color-coded dots (Green = Done, Orange = Doing, Red = Delayed)
- Click any date to view detailed tasks for that day
- Hover tooltips for quick task summaries
- Month navigation with previous/next controls

### AI-Powered Reports

- Weekly/monthly summaries generated by Groq LLM (llama-3.1-8b-instant)
- Smart recommendations based on task patterns
- Productivity scores and completion rate tracking
- Personalized insights like "Your most productive day is Tuesday"
- Automatic blocker detection and alerts

### Smart Reminders

- Scheduled email reminders (daily/weekly digests)
- Intelligent skip - no reminder if you already logged tasks
- Multiple channel support (Email, SMS, Slack ready)
- Configurable timing and frequency
- Digest mode for weekly summaries

### Searchable History

- Keyword search across all past tasks
- Filter by date range, status, and tags
- Export results to CSV/JSON for reporting
- Persistent search history
- Sort by date, status, or title

### Progress Analytics

- Real-time charts (Recharts) for visual progress tracking
- Completion rate trends over time
- Productivity streaks and active day tracking
- Goal alignment metrics
- Pie charts for status distribution

## 🚀 Quick Start (5 minutes)

### Prerequisites

| Tool | Version | Download |
|------|---------|----------|
| Node.js | v18+ | [nodejs.org](https://nodejs.org/) |
| Python | 3.10+ | [python.org](https://python.org/) |
| Supabase | Free tier | [supabase.com](https://supabase.com) |
| Groq API | Free tier | [console.groq.com](https://console.groq.com) |

### Installation

```bash
# 1. Clone repository
git clone https://github.com/AliNaseem123456789/IDoneThis.git
cd IDoneThis

# 2. Setup Backend
cd backend
npm install
cp .env.example .env
# Edit .env with your keys
npm run dev

# 3. Setup AI Service (new terminal)
cd ../chatbot
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python main.py

# 4. Setup Frontend (new terminal)
cd ../frontend
npm install
cp .env.example .env
npm start

```

### Database

```bash
create table public.users (
  id uuid not null default gen_random_uuid (),
  email text not null,
  password text not null,
  name text null,
  role text null default 'user'::text,
  created_at timestamp without time zone null default now(),
  constraint users_pkey primary key (id),
  constraint users_email_key unique (email)
) TABLESPACE pg_default;


create table public.user_reminders (
  id uuid not null default gen_random_uuid (),
  user_id uuid null,
  type text not null,
  delivery_method text[] null default array['email'::text],
  time text not null,
  days text[] not null,
  is_active boolean null default true,
  last_sent timestamp with time zone null,
  inserted_at timestamp with time zone null default now(),
  constraint user_reminders_pkey primary key (id),
  constraint user_reminders_user_id_fkey1 foreign KEY (user_id) references users (id),
  constraint user_reminders_type_check check (
    (
      type = any (array['reminder'::text, 'digest'::text])
    )
  )
) TABLESPACE pg_default;


create table public.tasks (
  id bigint generated always as identity not null,
  user_id uuid null,
  title text not null,
  description text null,
  status text null default 'Doing'::text,
  date_logged date null default CURRENT_DATE,
  created_at timestamp without time zone null default now(),
  updated_at timestamp without time zone null default now(),
  constraint tasks_pkey primary key (id),
  constraint tasks_user_id_fkey foreign KEY (user_id) references users (id) on delete CASCADE,
  constraint tasks_status_check check (
    (
      status = any (
        array['Done'::text, 'Doing'::text, 'Delayed'::text]
      )
    )
  )
) TABLESPACE pg_default;
```
